# Changelog

Notable project changes are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use [semantic versioning](https://semver.org/spec/v2.0.0.html) where practical.

## [1.0.2] - 2026-08-20

### Fixed

- Counterbalanced the strongest answer positions across all six role scenarios.
- Regression coverage that rejects repeated answer-position patterns and fixed-position scoring shortcuts.

## [1.0.1] - 2026-08-20

### Changed

- Rewrote learner-facing lessons, scenarios, progress labels, and navigation in clearer everyday language.
- Added a plain-language standard for future curriculum contributions.
- Updated project descriptions and the interface preview to match the clearer wording.

## [1.0.0] - 2026-08-20

### Added

- Six-question learning check-in and rule-based path ordering.
- Six modules, six role-specific scenarios, searchable resources, and printable guides.
- Deterministic curriculum studio with Markdown and JSON exports.
- Local progress, impact signals, import/export, and reset controls.
- Provider-neutral practice, storage, and analytics interfaces.
- Unit, component, adversarial import, responsive-route, learner-journey, and real-browser accessibility checks.
- Static GitHub Pages deployment with no login, paid API, or runtime tracking dependency.
- Public contribution guide, governance, support and conduct policies, structured issue forms, and pull request template.
