# Security and privacy policy

Brief & Verify has no application server, account system, model call, or tracking script. Learner state is stored in the current browser origin and can be exported as JSON.

## Report privately

Please use the repository’s [private vulnerability reporting form](https://github.com/edcadet10/brief-and-verify/security/advisories/new) for a security or privacy vulnerability. Do not open a public issue first.

Include:

- the affected route, file, or browser feature;
- a minimal reproduction;
- the practical impact and who could be affected; and
- a suggested fix or mitigation, when known.

Reports are reviewed on a best-effort basis. A validated report may be handled in a private advisory until a fix and coordinated disclosure are ready. There is no bug-bounty program.

## Protect report data

Do not include real personal, confidential, health, student, customer, or case data in a report or sample export.

Use a minimal fictional example, remove tokens and account details, and redact screenshots. For a non-sensitive defect with no security or privacy impact, use the public [bug report form](https://github.com/edcadet10/brief-and-verify/issues/new/choose) instead.
