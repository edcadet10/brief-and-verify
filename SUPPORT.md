# Support

Brief & Verify is an open-source project. Community support is best-effort; no response time or service availability is guaranteed.

Choose the path that fits:

| Need | Where to go |
| --- | --- |
| Setup or usage question | [Start a Discussion](https://github.com/edcadet10/brief-and-verify/discussions) |
| Teaching adaptation or early idea | [Start a Discussion](https://github.com/edcadet10/brief-and-verify/discussions) |
| Reproducible bug | [Use the bug form](https://github.com/edcadet10/brief-and-verify/issues/new/choose) |
| Curriculum correction or proposal | [Use the curriculum form](https://github.com/edcadet10/brief-and-verify/issues/new/choose) |
| Defined feature request | [Use the feature form](https://github.com/edcadet10/brief-and-verify/issues/new/choose) |
| Security or privacy vulnerability | Follow [the private reporting instructions](SECURITY.md) |
| Conduct concern | Follow the [Code of Conduct reporting guidance](CODE_OF_CONDUCT.md#reporting) |

Before posting, search existing issues and Discussions. Remove real personal, health, student, customer, case, authentication, and confidential information from screenshots, logs, exports, and examples.
